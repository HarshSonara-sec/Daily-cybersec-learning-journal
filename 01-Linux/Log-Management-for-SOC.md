# Log Management for SOC

## Why Logs Matter

Logs provide recorded events from systems and security controls. In SOC operations, log management is a core part of investigation and analysis.

## SOC Context

Let'sDefend's SOC Fundamentals course explicitly includes **Log Management** as a core topic and lists practical log-management skills among its expected outcomes.

For Linux systems, useful investigation work builds on existing knowledge of:

- Processes and services
- systemd
- System activity
- Network connections
- File and permission activity

## Investigation Mindset

When working with logs, focus on:

1. What event occurred?
2. When did it occur?
3. Which host, user or process was involved?
4. Is the event expected or suspicious?
5. What additional evidence is needed?

## SOC Connection

Linux administration knowledge is not separate from SOC work. Understanding normal processes, services and system activity helps an analyst recognize abnormal behavior and investigate alerts.

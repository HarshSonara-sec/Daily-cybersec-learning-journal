# Key Takeaways

- Connected and Local routes alone cannot reach remote networks.
- Static Routes must be configured for communication between different networks.
- Every route requires proper planning and bidirectional connectivity.
- MAC addresses change at every router hop, while IP addresses remain unchanged.
- Default Routes provide a fallback path for unknown destinations.
- Administrative Distance and Metrics influence route selection.
- Packet Tracer may not always behave exactly like real Cisco hardware.
- Troubleshooting strengthens networking knowledge more effectively than simple configuration.

## Overview

The **JetBrains** lab is a blue-team network forensics investigation focused on analyzing captured network traffic to identify a web-server compromise, investigate attacker activity, extract Indicators of Compromise (IOCs), identify persistence mechanisms, and map observed techniques to the **MITRE ATT&CK** framework.

## Learning Objectives

* Analyze network traffic using **Wireshark**
* Investigate suspicious HTTP/web-server activity
* Identify evidence of exploitation
* Reconstruct attacker activity from packet captures
* Extract attacker **IOCs**
* Identify persistence mechanisms
* Understand attacker execution and Command & Control activity
* Map observed techniques to **MITRE ATT&CK**

## Tools Used

### Wireshark

Used as the primary network-analysis tool to inspect packets, follow network streams, examine HTTP traffic, and identify suspicious activity.

Useful investigation techniques:

```text
http
tcp
ip.addr ==
ip.src ==
ip.dst ==
tcp.stream eq X
Follow → TCP Stream
Follow → HTTP Stream
```

### NetworkMiner

Can be used to extract and inspect network-related artifacts such as:

* Hosts
* IP addresses
* DNS information
* HTTP information
* Files
* Credentials/artifacts where present

### Brim

Useful for investigating PCAP data through higher-level network logs and queries, helping analysts identify suspicious connections and activity more efficiently.

## MITRE ATT&CK

The CyberDefenders lab identifies the following ATT&CK tactic areas:

* **Initial Access**
* **Execution**
* **Command and Control**

The investigation demonstrates how network evidence can be correlated with attacker techniques and represented using the MITRE ATT&CK framework.

## Key SOC Takeaways

### 1. PCAPs can reveal the attack timeline

Network traffic can be used to reconstruct what happened during an incident by correlating:

* Source IP
* Destination IP
* Ports
* Protocols
* Timestamps
* HTTP requests
* HTTP responses
* Network streams

### 2. HTTP traffic can contain valuable evidence

Web traffic may expose:

* Exploitation attempts
* Malicious requests
* Uploaded content
* Commands
* Attacker infrastructure
* Server responses

### 3. IOC extraction is an important SOC task

During an investigation, analysts should look for indicators such as:

```text
IP addresses
Domains
URLs
File names
File hashes
Suspicious commands
Malicious HTTP requests
User-Agent strings
```

### 4. Network evidence can support ATT&CK mapping

Instead of simply identifying that "an attack happened", a SOC analyst can map observed behavior to relevant attacker techniques and tactics.

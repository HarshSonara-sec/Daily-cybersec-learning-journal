# Topics Learned

## 1. What is Routing?

Learned that routing is the process of forwarding packets between different networks.

Understood that routers:
- Connect multiple networks.
- Examine destination IP addresses.
- Select the best path using the routing table.

---

## 2. The Routing Table on a Cisco Router

Studied the routing table and its purpose.

Learned that it stores:

- Destination networks
- Prefix lengths
- Next-hop addresses
- Exit interfaces
- Administrative information

Practiced understanding routing table entries.

---

## 3. Connected and Local Routes

Learned the difference between:

### Connected Routes

Automatically created when an interface is configured and active.

### Local Routes

Represent the router's own interface IP addresses.

Understood why both appear automatically in Cisco routing tables.

---

## 4. Routing Fundamentals (Route Selection)

Studied how routers decide where packets should be forwarded.

Learned that routers compare destination IP addresses against available routes before selecting the best match.

---

## 5. Dynamic Routing

Introduced to dynamic routing protocols.

Learned that dynamic routing:

- Automatically discovers networks.
- Learns routes from neighbouring routers.
- Updates routing information automatically.

Understood that dynamic routing reduces administrative effort in large networks.

---

## 6. Static Routing

Learned that static routes are manually configured by administrators.

Advantages:
- Simple
- Predictable
- Secure

Disadvantages:
- Manual maintenance
- Not scalable for large networks

---

## 7. Most Specific Matching Route

Studied one of the most important routing concepts.

Learned that routers always choose the route with the longest matching prefix (Longest Prefix Match).

Example:

If both exist:

- 192.168.0.0/16
- 192.168.1.0/24

Traffic destined for 192.168.1.x follows the /24 route because it is more specific.

Built a strong conceptual understanding of how Cisco routers make forwarding decisions and how different types of routes influence packet delivery.

---

# Key Takeaways

- Routing connects different networks.
- The routing table is central to packet forwarding.
- Connected and Local routes are created automatically.
- Static routes require manual configuration.
- Dynamic routing automates route learning.
- Longest Prefix Match is the primary rule used during route selection.

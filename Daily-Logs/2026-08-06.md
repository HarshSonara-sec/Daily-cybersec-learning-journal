Understanding the difference:

### Installer ISO

Used for:

* Installing Kali
* Modifying the installed system

### Live ISO

Used for:

* Testing hardware

## Solution 1: Analyze Existing Storage

Verified:

* Mount points
* Available space

---

## Solution 2: Use Live Environment for Partition Changes

Reason:

Running systems cannot safely resize their own mounted root partitions.

---

## Solution 3: Plan Storage Before Expanding

Created a safer approach:

1. Backup important data.
2. Verify disk layout.
3. Boot into Live USB.
4. Resize partitions carefully.
5. Verify filesystem integrity.

# 🧠 Lessons Learned

* Always understand the disk layout before modifying partitions.
* Never resize mounted partitions.
* A wrong ISO can waste time and create unnecessary troubleshooting.
* Live USB environments are essential for system-level disk operations.
* Storage planning is important for cybersecurity labs.
* VMware and vulnerable machines require significant disk space.
* Proper partition management is a valuable Linux administration skill.

# 🎓 Interview Questions

### 1. Why can't you resize a mounted partition?

Because the filesystem is actively being used by the operating system. Resizing while mounted can cause corruption or data loss.

---

### 2. What is the difference between Live USB and Installer ISO?

A Live USB runs an operating system temporarily without installation, while an Installer ISO is designed to install the OS.

---

### 3. Why is disk layout knowledge important?

Incorrect partition operations can destroy operating systems and data.

---

Security labs require:

* Virtual machines
* Large tools
* Wordlists
* Packet captures
* Multiple environments

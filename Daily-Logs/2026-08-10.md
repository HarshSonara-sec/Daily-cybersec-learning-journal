## 2. System Security / Kali Hardening — Study & Planning
Reviewed how to securely operate Kali Linux as a daily cybersecurity workstation.

### Security Principles
- Avoid using `root` for normal daily work
- Use `sudo` only when administrative privileges are required
- Minimize unnecessary running services
- Review listening ports before disabling services
- Understand firewall rules before changing them
- Keep the rolling system updated in a controlled manner
- Maintain backups before major system changes

### Attack-Surface Audit Plan
Planned a practical audit of the current Kali installation:

```bash
whoami
id
sudo -l
sudo ss -tulpn
systemctl --type=service --state=running
sudo nft list ruleset
lsblk -f
```

The goal is to identify:
- Current user privileges
- Listening services
- Running services
- Firewall configuration
- Storage / encryption status

**Important:** No unnecessary services or firewall rules were changed during this review.

# Evening Session – VMware & Metasploitable 2 Lab

## 🎯 Objective

* Install VMware Workstation Pro on Kali Linux.
* Deploy Metasploitable 2.
* Build the first isolated penetration testing lab.
* Perform initial reconnaissance and service enumeration.

---

## 🛠️ Practical Work Completed

### VMware Installation

* Verified CPU virtualization (VT-x) support.
* Confirmed matching Linux kernel headers were installed.
* Installed VMware Workstation Pro successfully.
* Verified VMware launched without module or kernel errors.

### Metasploitable 2 Setup

* Imported the Metasploitable 2 virtual machine.
* Configured networking using a Host-Only adapter.
* Verified communication between Kali Linux and the target VM.

### Initial Reconnaissance

Performed an initial Nmap scan using:

* Default NSE scripts (`-sC`)
* Version detection (`-sV`)

The scan identified numerous intentionally vulnerable services including:

* FTP (vsftpd)
* SSH
* Telnet
* SMTP
* DNS
* HTTP (Apache)
* SMB
* NFS
* MySQL
* PostgreSQL
* VNC
* Tomcat
* Java RMI

---

## 🔍 Enumeration Performed

### FTP

* Verified anonymous login was enabled.
* Confirmed successful authentication.
* Attempted directory listing.
* Tested navigation within the FTP service.

### SMB

Enumerated available shares.

Discovered:

* tmp
* opt
* print$
* IPC$
* ADMIN$

Successfully connected to the **tmp** share using anonymous authentication.

Observed:

* Directory listing available.
* File access restrictions in place.
* Write access not yet tested successfully.

### Web Enumeration

Used Gobuster to enumerate web directories.

Discovered:

* `/phpMyAdmin`
* `/dav`
* `/test`
* `/twiki`
* `phpinfo.php`

These services will be investigated during the vulnerability assessment phase.

---

## 📚 Key Lessons Learned

* Enumeration should always precede exploitation.
* Multiple tools reveal different parts of the attack surface.
* Version detection is essential for identifying potential vulnerabilities.
* Anonymous access does not necessarily imply unrestricted permissions.
* Findings from multiple services should be correlated before selecting an attack path.

---

## 📌 Challenges Faced

* Slow download speeds for Metasploitable 2 mirrors.
* Several download mirrors failed before obtaining a working copy.
* FTP directory navigation behaved differently than expected.
* SMB allowed anonymous enumeration but restricted access to certain resources.

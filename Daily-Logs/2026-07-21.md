# Topics Learned

## 1. Switch Interfaces

Learned that every switch port is an interface used to connect devices to the network.

Covered:
- Physical interfaces
- Interface numbering
- Accessing interfaces through Cisco IOS CLI
- Configuring interfaces individually

---

## 2. Interface Speed and Duplex

Studied the importance of interface speed and duplex settings.

Covered:
- 10 Mbps
- 100 Mbps
- 1 Gbps
- Full Duplex
- Half Duplex

Learned how incorrect speed or duplex settings can cause poor network performance.

---

## 3. Speed and Duplex Auto-Negotiation

Learned how modern Ethernet devices automatically negotiate:

- Speed
- Duplex mode

Understood that:
- Auto-negotiation usually selects the highest supported speed.
- Manual mismatches can create duplex mismatch problems.
- Auto-negotiation should normally remain enabled unless specifically required otherwise.

---

## 4. Interface Status

Learned how to determine whether an interface is operational.

Important interface states:

- Administratively Down
- Down
- Up
- Up/Up

Practiced interpreting interface status messages.

---

## 5. Interface Counters and Errors

Studied interface statistics used for troubleshooting.

Covered:

- Input packets
- Output packets
- CRC Errors
- Frame Errors
- Runts
- Giants
- Dropped packets
- Output errors

Learned that interface counters provide valuable information when diagnosing physical or network-layer problems.

---

# Practical Understanding

Learned how network administrators verify interface health using Cisco IOS commands and understand whether issues originate from cables, duplex mismatches, hardware faults or excessive traffic.

---

# Key Takeaways

- Every switch port is an independent interface.
- Speed and duplex mismatches are common causes of connectivity problems.
- Interface status quickly reveals operational issues.
- Error counters are essential for troubleshooting networks.

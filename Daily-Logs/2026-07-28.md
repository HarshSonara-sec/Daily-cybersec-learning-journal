## 💡 Key Concepts Learned

- CIDR provides flexible IP addressing.
- Subnetting improves address utilisation and network organisation.
- Prefix length determines the network and host portions of an IP address.
- VLSM allows different subnet sizes within the same network.
- Larger host requirements should always be allocated first during VLSM planning.
- Routers forward packets using IP addresses, while switches forward frames using MAC addresses.
